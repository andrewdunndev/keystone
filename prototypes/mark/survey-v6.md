## 0. Premise check (read first)
The cairn HOME hero is not thin-wire. It is four filled, faceted stones, and at rest it looks much like the v5 arch. What reads "thin
wire" on the home page is the drafting register (section 1b): `iso.js` solids with 0.8 edges, dash-dot ground plates, hairline hidden
lines. The builder has to pick which of these the operator meant; the measured facts for both follow.

## 1. cairn.dunn.dev home hero
### 1a. The cover (home `.cover-fig`), measured
- Source: `src/pages/index.astro:35-37` puts an empty `<div class="cover-fig">`; `guide/walk.js:81-146` `cover()` fills it from
  `guide/kit/cairn.js`, a file generated by `just brand` from `src/brand/cairn.ts` + `mark.ts` (`guide/kit/cairn.js:1`). It is JS-built SVG,
  no CSS keyframes.
- viewBox `-186.5 -223.2 377.7 321.8` (`guide/kit/cairn.js:2`), width 100%, height auto, overflow visible (`guide/walk.css:89-90`). Not
  64-unit.
- Geometry: 4 stones, `src/brand/cairn.ts:10-14`; each is 4 rings (foot, belly, shoulder, top; `cairn.ts:25`) with arc=2 so about 20
  outline points; faces from ring pairs (`cairn.ts:82-93`). Elevation 30 degrees, true iso azimuth 45 (`cairn.ts:66-68`, `sE = sin(30)`).
  Rounded slabs with a deterministic jitter (`cairn.ts:21,39`), not hard-edged rings.
- Lines per stone (`mark.ts:60-87`): one silhouette fill, then faces grouped by tone, each group one path filled AND stroked in its own
  tone at 0.25 (`mark.ts:73`; emitted as 0.6 in `kit/cairn.js`, `stroke-width="0.6"`), a top polygon, a cast-shadow polygon clipped to the
  stone below (`mark.ts:78`, fill `#0a0a0a` at 0.14), and ONE visible edge: silhouette hull, `fill="none"`, stroke `#404040` (`tone.ts:7`),
  width 1.25 in the guide cover (1 in hero.svg, 1.5 in avatar; `scripts/brand.ts:17-18`). So exactly one dark line layer per stone; internal
  seams are same-tone and nearly invisible. 89 polygons + 8 paths in the file; zero `vector-effect` (`grep -c vector-effect` = 0).
- Fills: opaque. Stones white `#ffffff` top, side tones mixed 7/16/30% toward `#0a0a0a` (`tone.ts:20-23`); moss cap `#4a6741` mixed
  18/36/55. No fill:none bodies. Hidden lines: none drawn; the painter's order (base first) hides, and back faces are culled by the
  view-vector test (`cairn.ts:89`).
- Ground: one diamond polygon, `stroke var(--hair-2)` `.7`, `stroke-dasharray 12 3 2 3` (dash-dot centerline), `walk.css:92`. This is the
  only "wire" in the cover.
- Scale (computed, not screenshot): at 1280 the cover column is about 504 px (`.cover .wrap` grid 1.1fr / .9fr, gap 48, rail and gutter 56;
  `walk.css:80,268`), so 1.33 px per unit: edge 1.25 renders about 1.7 px. At 375, `.cover-fig{max-width:360px}` (`walk.css:284`) inside 16
  px gutters (`walk.css:280`) gives 343 px, 0.91 px per unit: edge about 1.1 px. Strokes scale with the SVG (no non-scaling).
- Animation (`walk.js:65-146`): drop, JS rAF, no CSS. `DROP = {lead:200, lag:300, ms:820, land:0.56, shade:300}` (`walk.js:69`). Stone i
  starts `200 + 300 i` ms in, falls from `44 + 14 i` px above (`walk.js:71`) with quadratic accel `(u/.56)^2`, a +1.4 deg rotate, lands at
  56% of its 820 ms, overshoots `-2.5 px` with `outCubic` (to u=.70), returns with `inOut` (to .84), then a last `-0.25` settle to 1.0.
  Opacity ramps over the first 22% of the fall. Cast shadows fade in with `outCubic` over 300 ms after landing (`walk.js:136-138`). End = 200
  + 3*300 + 820 = 1920 ms. Hover (`pointerenter`) lifts stones apart 26 px per course (`LIFT`, `walk.js:70`); leave drops them back with a
  one-cycle rock. Plays once on load.
- Reduced motion: `mqStill = print, (prefers-reduced-motion: reduce)` (`walk.js:68`); `if (mqStill.matches) return;` before the rAF
  (`walk.js:129`) so the finished frame is the still, and `lift()` is a no-op (`walk.js:123`).

### 1b. The wire register (what actually looks like thin lines)
- Iso solids, `guide/kit/iso.js` (identical to reference `cairn/iso.js`): `box()` draws side faces (`data-tone` 0-3 by normal), a top face,
  then ONE `iso-edge` path: top ring plus the two front verticals plus a base L (`iso.js:34-46`). Back faces culled (`iso.js:38`), so
  hidden-line handling is omission, never dash. Elevation `E = PI/6` (30), azimuth `A = PI/4` (`iso.js:6`).
- CSS (`walk.css:199-214`): faces `stroke:none`, fills `--tone-0..3` `#f2f2f0 #e8e8e5 #dadad6 #c8c8c3` (`walk.css:12-15`), top `#fff`;
  `.iso-edge` stroke `--ink` `#161616`, width .8, round joins and caps; `.ghost` edge `--grey` dash `3 2.5` width .7; `.iso-plate` `--hair-2`
  .7 dash `12 3 2 3`; `.wire` ink 1; `.hidden-line` grey .7 dash `4 3` (`walk.css:227`); `.leader` grey .7. No `vector-effect` anywhere in
  walk.css.
- Slab rings with true hidden-line removal: the plate figure (`guide/kit/interlude.js:20-34`): each course is a stacked iso box (30
  degrees, `CAM {k:1.35}`, `COURSE 20`, `WIDTHS` 236 down to 96) built as TWO boxes, an ink-filled `under` box that occludes courses behind,
  and the face box; edges on ink are paper stroke at opacity .8 (`walk.css:107-109`), faces `rgba(252,252,250,.06)` and tops .22/.36 alpha,
  ground plate paper .8 at .45 opacity, dash-draw (`pathLength=1`). This is the closest thing to "wire slabs": translucent faces, one .8
  edge, ground drawn in.
- Plate cap drop: `interlude.js:36-47`: ground `drawIn` 0-600 ms, lower courses `fadeIn` 0-800, cap `assemble` from `DROP=120` units above,
  820 ms, `outBack` 1.2, starting 400 ms (`MS = 1220`). Static modes show it standing (`walk.js:41-62`: `isStatic()` = print, reduced-motion,
  or max-width 860). Plates live in the guide, not on Home.
- The Home stage figure `figures/whole-path.js` is the on-page drafting figure (two rows of four iso sheets over wires, 720x520, labels at
  13 units).

### 1c. v5 arch hero versus all of that (what to change)
- `ks:prototypes/mark/arch/mark.mjs`: 11 solids, 86 paths, 1 polygon, 14 distinct fills. Large form = `ramp()` 8 steps per body (`:27-35`;
  stone k 0,4,7,11,16,22,30,38; key 0,10,18,27,36,45,55,63), one path per tone step, each filled and stroked 0.2 (`:296`), then the
  silhouette edge `#404040` width 1 (`:298`). Cairn uses 4 tones per body (top/left/right/shade) at the same 0.25 seam stroke, so v5 has 2x
  the tone steps and the same single edge.
- Hero: `hero()` `:321-340`, viewBox `0 -21 64 85` (`hero.svg`, 18270 bytes), one CSS animation `keystone-drop 900ms linear 400ms both`
  with per-keyframe timing (cubic-bezier .5,0,1,.6 fall to 58%, ease-out, rock .5 deg), dashed landing outline `stroke-width .6 dasharray 1.6
  1.2`, and `@media (prefers-reduced-motion:reduce){...animation:none}` inside the SVG `<style>`. One stone drops; cairn drops all four.
- To go wire: replace the 8-step face fills with `fill:none`/paper fill and hairline strokes (iso edge .8 range, back faces culled,
  `#161616`/`--hair` tones), keep the 30-degree camera and `fit()` box; keep exactly one dark-edge layer. The tone ramp (`:27-35`) and
  `stoneMarkup` fill block (`:292-298`) are the two places that change; geometry (`sections`, `build`) stays.
