# Security

Report a vulnerability as a confidential issue: open [a new issue](https://gitlab.com/dunn.dev/keystone/-/issues/new) and tick "confidential" before submitting. Leave key material out of the report.

Only the latest tag is supported. keystone has a single maintainer, so responses are best effort.

The security model, including the trust root, is in the [README](README.md#security-model).
